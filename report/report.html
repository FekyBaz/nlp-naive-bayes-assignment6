Assignment 1: Text Classification with Naive Bayes

Student ID: 2305467  |  GitHub: FekyBaz  |  Repository: github.com/FekyBaz/nlp-naive-bayes-assignment6
This report summarizes a bag-of-words text classifier built for a four-class sentence dataset. A Multinomial Naive Bayes model is implemented from scratch with Laplace smoothing and log-space scoring, then compared with scikit-learn's MultinomialNB on exactly the same 68/17 split. Both models reach 100.00% training accuracy and 82.35% test accuracy (14/17 correct), and make identical predictions on both splits (training agreement 100%, test agreement 100%). The small test set and the gap between training and test accuracy call for cautious interpretation.

1. Dataset

The repository includes synthetic_text_data.csv with 85 English sentences and four labels: Entertainment 19, Politics 21, Sports 15, Technology 30. The file has no missing values, no duplicate texts, and no empty sentences. Sentences average 12 alphabetic tokens (range 8–16). The classes are imbalanced: Technology is the largest class and Sports the smallest. Figure 1 (on page 2) shows the class distribution and the most frequent training words. As expected without stopword removal, function words such as “the”, “are”, and “to” dominate the frequency ranking.

2. Preprocessing, split, and vocabulary

Each sentence is lowercased and tokenized with the regular expression [a-z]+, which removes punctuation, digits, and non-ASCII characters. Rows that become empty after tokenization are dropped (none did). The cleaned data is split with test_size=0.2, random_state=42, and stratification, producing 68 training and 17 test sentences. The vocabulary is built from the training tokens only: 391 distinct words. Test-only words are safely ignored, giving 69 unseen test types and 0 test documents with no in-vocabulary tokens. No test sentence is used for the vocabulary, word frequencies, or word clouds.

3. Models

Manual Multinomial Naive Bayes. For each class c, the prior and smoothed word likelihood are estimated from the training counts:

P(c) = Nc / N      P(w | c) = (count(w, c) + α) / (Σw count(w, c) + α |V|)
ŷ = argmaxc [ log P(c) + Σw xw log P(w | c) ]

with α = 1 (Laplace smoothing) and |V| = 391. The implementation follows the section's four-step formulation (priors, vocabulary/denominators, likelihoods, class scores) and builds BoW vectors with Counter. Counts are weighted by the BoW vector and summed in log space to avoid numerical underflow. Unknown words contribute nothing because they are absent from the vocabulary. scikit-learn baseline. MultinomialNB(alpha=1.0) is trained on the same matrices and labels. Because both models use empirical priors and the same smoothed multinomial likelihood, identical predictions are expected.

6. Discussion and limitations

The manual implementation matches scikit-learn exactly, which validates the count aggregation, prior calculation, Laplace smoothing, and log-space scoring. The main performance limitation is the data: 85 short synthetic sentences, noticeable class imbalance, and a 17-sentence test set. The model also uses a simple BoW representation with no stopword removal, stemming, n-grams, or hyperparameter tuning. These choices keep the assignment scope controlled but mean the reported accuracy should not be read as a generalisation estimate. Cross-validation on a larger, more balanced corpus would give a more reliable comparison. The test set was used only for final evaluation; all vocabulary and word-based exploratory analysis came from the training split.
